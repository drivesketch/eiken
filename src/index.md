# 英語の練習帳

簡単な英語を、自然に読んで、聞いて、話せるように。

## 教材

### [5級 基本文型・語法の復習](./grade5-review.md)

学校・家族・買い物など、6つの場面で基本の表現を復習します。

## 練習の流れ

1. **Read Aloud** — 意味を考えながら、声に出して読む。
2. **短い暗唱** — 2〜4文ずつ、本文を見ずに言ってみる。
3. **Questions** — 本文を伏せて、英語の質問に答える。
4. **Change!** — 主語や言葉を変えて、新しい英文を作る。

全文を丸暗記する必要はありません。簡単な英文がすっと口から出ることを目指しましょう。
