# 英検4級 単語・熟語

英語を声に出して、意味を思い出そう。迷ったら「訳を表示」で確かめよう。

<VocabularyStudy :groups="data" />

::: details このページの使い方と収録内容
まずは50項目ずつ、英語を読んで日本語の意味を答えてみましょう。
「日本語訳を表示」をONにすると、表示中の範囲の訳をまとめて確認できます。
初期状態はOFFです。単語ごとの「訳を表示」も使えます。
分類や範囲を切り替えると、訳はもう一度隠れます。

1ページに50項目ずつ表示します。前後の矢印や範囲のメニューでページを切り替えられます。
「すべての分類」を選ぶと、全項目を番号順に50項目ずつ練習できます。
印刷時は、選択中の範囲の訳も表示されます。

参照元は `references/grade4/vocabulary/` の日本語訳ありPDF全3冊です。

| 分類 | 項目数 | 原本の番号 |
| --- | --- | --- |
| 学校で習う単語 | 349 | 1～349 |
| 英検にでる単語 | 251 | 350～600 |
| 熟語 | 100 | 601～700 |

「学校で習う単語」のPDFは全16ページの合本です。
8～12ページは「英検にでる単語」のPDF全5ページ、13～16ページは「熟語」のPDF全4ページと同じ内容です。
同じ番号の項目は一度だけ収録しています。

番号・順序・語義は原本に合わせています。同じ綴りでも意味が異なる項目は別々に収録しています。
ルビは省略し、波線などの表記を統一しています。
:::
